# 영어 과제 AI 채점 도우미

구글 폼·문서·시트와 Gemini로 영어 글쓰기·발표 대본 과제를 루브릭대로 채점하고, 학생별 피드백 문서를 만들어 보내는 Google Apps Script입니다. 제주대 교양영어 수업에서 Claude로 하던 채점 과정을 구글 도구로 옮겨 만들었습니다(2026 구글 강사 교육 "업무자동화" 과제).

```
구글 문서로 작성 → 폼에 파일 업로드 → 제미나이(루브릭 채점) → 피드백 문서 생성 → 교사 검토 → 문서 공유 + 메일
```

## 가장 쉬운 시작: 템플릿 사본 만들기

**[템플릿 사본 만들기](https://docs.google.com/spreadsheets/d/17wZTxVokPcSDoeyFufnO5zshnAPKFpptvZc3A29z4-4/copy)** 링크를 열고 "사본 만들기"를 누르면, 코드가 들어 있는 스프레드시트가 내 드라이브에 생깁니다. 그다음:

1. 사본을 열면 위쪽에 **🤖 AI 채점** 메뉴가 생깁니다 (몇 초 걸림).
2. **① Gemini API 키 등록** — [Google AI Studio](https://aistudio.google.com/apikey)에서 발급한 키를 붙여넣습니다. 처음 한 번 권한 허용 창이 뜨면 *고급 → (프로젝트)로 이동 → 모두 선택 → 계속*.
3. **② 채점기준·예시 만들기** — [채점기준] 시트와 예시 학생 3명의 대본 문서가 생깁니다. [채점기준]을 내 과제에 맞게 고칩니다.
4. 예시 시트에서 **⑤ 채점 안 된 행 모두 채점** → 점수와 "피드백 문서 열기" 링크가 생기면 성공.
5. **③ 과제 제출 폼 만들기** → 폼 편집 화면에서 *파일 업로드* 질문(제목: 대본 파일)을 한 번 직접 추가하고, 학생용 링크를 LMS에 올립니다.
6. 피드백 문서를 검토·수정한 뒤 [상태]를 **승인**으로 바꾸고 **⑥ [승인] 행에 피드백 보내기**.

자세한 순서와 문제 해결은 [docs/guide.html](docs/guide.html)에 있습니다.

## 직접 설치하기

새 스프레드시트 → **확장 프로그램 → Apps Script** → 기존 코드를 지우고 [`Code.gs`](Code.gs) 전체를 붙여넣기 → 저장 → 시트 새로고침.

## 하는 일

| 메뉴 | 내용 |
|---|---|
| ① API 키 등록 | Gemini API 키를 스크립트 속성에만 저장 (코드·시트에는 남지 않음) |
| ② 채점기준·예시 | 루브릭 시트(영어 사용 4 · 초점과 구성 3 · 표현 2 · 완성도 1)와 예시 대본 문서 3개 |
| ③ 제출 폼 | 이름·학번·영상 링크 질문이 있는 폼을 만들어 시트에 연결 |
| ④⑤ 채점 | 구글 문서·Word·PDF에서 글을 꺼내 채점 → 단어 수, 항목별 점수, 별도 감점, 피드백 문서, 채점 근거, 확인 사항 기록 |
| ⑥ 보내기 | 승인한 학생에게만 피드백 문서를 보기 권한으로 공유하고 링크를 메일로 발송 |

**점수 계산은 코드가 합니다.** 제미나이는 항목별 점수와 근거만 정하고, 0.25 단위 맞춤·합계·영상 미제출 감점(−0.5)·만점 유보(−0.25)는 코드가 규칙대로 계산합니다.

**원문 대조 검사.** 피드백에 원문에 없는 인용이 있거나, 수정 대본에서 표시를 걷어 낸 글이 원문과 다르면 [확인 사항]에 표시합니다. AI가 학생 글에 없는 내용을 지어내는 일을 잡기 위한 장치입니다.

**서버 붐빔 대비.** Gemini가 붐비면(429·503) 기다렸다가 다시 시도하고, 그래도 안 되면 다음 Flash 모델로 넘어갑니다. 모델 목록은 `Code.gs` 맨 위 `MODELS`에서 바꿀 수 있습니다.

## 피드백 문서 구성

Instructor Comment(점수·요약) → 루브릭 표(항목 → Script subtotal → 별도 감점 → Total) → Comments(잘된 점·고칠 점, 들여쓰기로 문단 구분) → What changed, and why → Revised Script(학생 원문에 **굵은 파란 글씨** = 고친 말, ~~취소선~~ = 지울 말. 없는 내용은 지어내지 않고 빈칸 `______`).

## 주의

- **AI 점수는 초안입니다.** 같은 글도 실행할 때마다 점수가 조금 다를 수 있고, 틀리지 않은 표현을 고치기도 합니다. 반드시 교사가 검토한 뒤 보내세요.
- Gemini API **무료 등급**에 보낸 내용은 구글의 서비스 개선에 쓰일 수 있습니다. 실습은 예시 데이터로 하고, 실제 학생 글을 넣기 전에 학교의 개인정보 지침을 확인하세요.
- 파일 업로드로 제출하려면 학생이 구글 계정으로 로그인해야 합니다. 한글(hwp) 파일은 읽지 못합니다.
- 이 스크립트는 구글의 검증을 받지 않은 개인용 스크립트라 처음 실행할 때 "확인되지 않은 앱" 경고가 나옵니다. 내 계정에서 내가 실행하는 코드이므로 *고급 → 이동*으로 진행하면 됩니다.
